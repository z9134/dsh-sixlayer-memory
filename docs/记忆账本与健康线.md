# 记忆账本与健康线（补齐自《记忆系统实施单》5.2 / 5.3）

日期：2026-11-03
版本：1.8.0

## 账本（ledger）

- 文件：`dsh-memory-data/ledger.json`
- 内容：每条 active 记录的 `{sha256, len}`
- 工具：`mem_ledger({ action: "init" | "sync" | "verify" })`
- 纪律：**先 sync 再 verify**；sync 只补新 id，绝不覆盖
- 与审计链的分工：审计链管操作顺序，账本管每条正文的指纹

### 负例测试（已内置 p24）

```
篡改一条正文 → verify 返回 { ok: false, changed: [id] }
```

## 每日健康一行

- 位置：`dsh-memory-data/reports/health.log`
- 格式：`[memory] 2026-11-03 total=27 active=27 s=5 pending=0 ledger=OK audit=OK`
- 频率：启动时 + 每 6 小时（随日报一起写）
- 工具：`mem_health({})` 随时手动打一行

## 实测

```
ledger init: 27 条
sync: added=0 total=27
verify: ok=true
[memory] 2026-11-03 total=27 active=27 s=5 pending=0 ledger=OK audit=OK
```
