## 一期：采集与存储

- 新表 `affect_events`：事件 ID、会话、来源、发生时间、标签、效价、唤醒度、≤80 字脱敏摘要、摘要哈希、触发词
- 采集源：`~/.dsh/sessions/--…-dsh-qqbot-workspace--/session-<id>/session.v4.jsonl.zstd`
  - 多帧 zstd：按魔数切帧，逐帧解压
  - 只收 `user/message` 且 `data.source.kind === 'user'`
    （runtime-context / time-context / skill-catalog 都是注入消息，跳过）
  - 按 (session_id, excerpt_hash, occurred_at) 去重
- 词表扩充：难过 / 不开心 / 心情 / 烦 / 累 / 压力 / 焦虑 / 委屈 / 生气 / 崩溃；
  开心 / 高兴 / 爽 / 棒 / 期待 / 满意
- 工具：`mem_affect_report`、`mem_affect_ingest`
- 后台：每 10 分钟自动采集（`config.affect.enabled=false` 可关）
- 面板：观测页「今日情绪事件（QQ 采集）」+ 立即采集按钮

## 三期：情绪提醒

- `lib/memory/affect-alert.js`
- **注入提示**：近 N 小时（默认 3）负面/紧急 ≥ 阈值（默认 2）时，
  记忆快照追加一行「情绪提示：先安抚再解决，语气放慢，不追问细节」
- **主动通知**：每 30 分钟检查；尖峰时走现有邮件/飞书通道；同一尖峰 6 小时冷却
  （`meta.affect_last_notify`）
- 开关：`affect.hint=false` / `affect.notify=false`
