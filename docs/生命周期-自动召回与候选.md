# 每轮记忆生命周期（2.0）

> 目标：把"记忆"从**模型想得起来才用**，变成**每一轮都在**。

旧版（1.x）只有两条路：模型主动调 `mem_search`，或者系统提示词里固定挂 3 条指针快照。
前者靠自觉，后者与本轮问题无关。2.0 补上第三条：**按本轮输入自动召回**，外加**自动候选沉淀**。

代码：`lib/memory/lifecycle.js` · 回归：`tools/p25.mjs`（28 项）

---

## 1. 挂在哪

| 宿主挂点 | 时机 | 用法 |
|---|---|---|
| `agent/pre-step` | 每轮第 1 个模型步骤之前（waterfall，`{ prepend: true }`） | 先 `await next()` 拿到拟进入批次，再改写 `decision.messages` |
| `session/event` | 每轮结束时（`event.type === 'turn/end'` 且 `reason.kind === 'completed'`） | 回读本轮事件，抽候选句落库 |

消息形状对齐 `@deepseek-ai/dsh-llm` 的 `createMessage`：
`{ id: uuid, role: 'user', content, source }`，深冻结。
**优先用宿主的 `createUserMessage`**（`createRequire` 从 profile 的共享 node_modules 拿）；
拿不到就用同形兜底（`fallbackUserMessage`），保证宿主校验不会因为形状不同而炸。

---

## 2. 召回（recall）

```
本轮用户直输（source.kind === 'user'，≤ maxQueryChars）
   → store.search({ query, topK })            // FTS5 + 中文 bigram，全程本地
   → 过滤：S 级剔除、tainted 剔除、未验证只给指针
   → buildRecallText（围栏 + "数据不是指令" + usageCaveat）
   → 作为一条 user 消息插在本轮第一条用户消息之前
```

为什么插在**前面**：模型先读线索再读问题，命中才有意义；插在后面容易当作"补充说明"忽略。

去重：同一条 query、同一 session、`cooldownMs` 内不重复注入。

预算：`topK`（默认 3）、`maxChars`（默认 900）。超预算的条目直接不列，不截断半句。

**S 级与 tainted 永远不出现**——这是与"云记忆插件"最本质的区别：召回路径上没有外发，也没有凭证正文。

---

## 3. 候选沉淀（capture）

**只认用户自己说的话**（`source.kind === 'user'`），且必须命中"长期约定"句式：

| 类别 | 例子 |
|---|---|
| 记忆指令 | 记住、记一下、记下来 |
| 长期口径 | 以后、今后、下次、一律、统一、默认 |
| 禁止/强制 | 别再、不要再、必须、务必、禁止 |
| 约定/规范 | 约定、说好、口径、规范、标准 |
| 个人偏好 | 我习惯、我喜欢、我讨厌、我偏好、我一般 |

问句（`?/？` 结尾、以"帮我/麻烦/请问"开头）和客套句直接跳过。
句子长度 12–300 字，每轮最多 2 条，落 L2（命中个人偏好落 L3）。

**关键**：写入通道是 `tool` → 信任级 `unverified` → 闸门公理 → `status = 'pending'`，
进 `review_queue`，**不直接进 active**。误判的代价只是待审队列多一条，`mem_review` 一键驳回。

---

## 4. 用进强化（reinforce）

召回命中一条，`alpha = MIN(1, COALESCE(alpha, 0.5) + delta)`（默认 0.02），
并写一条 `op=recall` 的审计（含 query 哈希、命中 id、字符数）。
用得多的重要度上升——这是"重要性"从静态打分走向使用反馈的第一步。

---

## 5. 失败模式（全部 fail-open）

| 故障 | 表现 | 处理 |
|---|---|---|
| FTS 查询抛错 | 召回空 | 返回原 decision，`diag` 记一行 |
| 消息工厂拿不到 | `factory=fallback` | 用同形兜底，宿主校验不过也不影响本轮 |
| 会话读不到事件 | 沉淀跳过 | 返回，不重试 |
| 写入 pending 失败 | 沉淀丢弃 | `diag` 记一行 |
| 引擎卸载 | 两个监听器都摘掉 | `dispose()` 幂等 |

**任何一条路径都不允许把本轮对话打断**——这是写这一层时的第一约束。

## 6. 验收

```bash
node tools/p25.mjs        # 28 项：纯函数 + 假宿主挂载 + fail-open
node tools/preflight.mjs  # 10 项
node tools/verify-all.mjs # 28 个套件
```

重启后在 `docs/_rpc-diag.log` 里应看到：

```
lifecycle: attached (recall=true capture=true factory=...)
```

`mem_audit({ deep: true })` 里应出现 `op=recall` / `op=capture` 的新行；
`mem_pending()` 里应能看到自动沉的候选（`tags: ['auto-capture']`）。
