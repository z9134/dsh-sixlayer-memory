# 30 秒演示脚本

用于录屏或给朋友演示。每一步都只依赖已经装好的东西，不需要联网。

## 场景：让 AI 记住一次事故，过一会儿自己想起来

### 1. 写入（5 秒）

在对话里说：

> 记住：昨天插件启动崩溃，是因为 profile 的 package.json 带了 UTF-8 BOM。

等价命令：

```
mem_write({ content: "插件启动崩溃，原因是 profile 的 package.json 带了 UTF-8 BOM", layer: "L2", tags: ["bug","bom"] })
```

预期：返回 `record_id`，情绪标签为 `negative`（“崩溃”命中词表）。

### 2. 检索（5 秒）

```
mem_search({ query: "启动崩溃" })
```

预期：命中刚才那条，摘要带 `[L2/A]`。

### 3. 联想（5 秒）

```
mem_associate({ query: "package.json" })
```

预期：返回与 BOM 崩溃相关的记忆，每条带 `理由：标签:xxx、语义`。

### 4. 观测（5 秒）

设置 → 记忆底座 → 观测：

- 注入次数 / 平均指针
- 情绪分布：负面计数 +1
- 近 14 天趋势：今天那根柱子出现红色段

### 5. 右侧栏对照（5 秒）

打开右侧栏：

- 「Context」= 上下文构成（dsh-context）
- 「记忆」= 注入/召回/情绪（本插件）

### 6. 交接（5 秒）

```
mem_handoff({ scene: "demo" })
```

预期：返回结构化交接（已知事实 / 已试过 / 下一步），可直接贴给下一个会话。

---

## 录屏建议

- 全程 30–40 秒，不要读文档
- 重点展示「联想」和「观测」两个面板，它们最直观
- 结尾一句：**“它不是记住聊天记录，是记住教训。”**
