## 在界面上怎么用

设置 → 工作台 → **零件**：

1. 上半部分是**已装零件**（5 个内置：profile / recent / lessons / scene / associations）
2. 下半部分是**零件库**：
   - 搜索框：按名称 / 作者 / 说明过滤
   - 分类按钮：按类别筛选
   - 每条显示：名称、stars、分类、是否官方审核、作者、仓库、**安装命令**
   - 点「复制安装命令」→ 粘到终端执行 → 重启

## 一键安装 / 卸载

零件条目上有「安装」按钮，已装插件有「卸载」按钮（v1.2.0 起）：

- 安装：确认 → 调官方 CLI（`dsh plugin --profile desktop add <spec>`）→ 自动登记到 `dsh.profile.bundles` → 提示重启
- 卸载：从 bundles 移除 → `dsh plugin remove <name>` → 提示重启
- 保护：**不能卸载工作台自身，也不能卸载 `@deepseek-ai/*` 内置包**
- 失败会原样返回 CLI 输出，不吞错误

安装规格：仓库地址自动转成 `github:作者/仓库`；也支持 npm 包名。

> 安全提示：安装第三方插件等于往 profile 里写代码，**装前先看作者与 stars，优先「已审」**。
> 装完重启前，建议先跑一次 `node tools/preflight.mjs`。

## 需要什么零件

直接说用途即可，比如「我要一个能画图的零件」「要一个网页预览的零件」，我从库里挑合适的、扫一遍、装好，再让你重启。

## 安装通道升级（1.5.1）

- 当 GitHub 仓库**没有根 package.json**（monorepo / 只发 npm 包）时：
  改用 **npm 搜索**，按仓库地址匹配到对应 npm 包再安装
  例：`MemTensor/MemOS` → `@memtensor/memos-cloud-dsh-plugin`
- 卡片上新增「**复制安装链接**」：一键复制仓库地址，粘到终端或发给别人
- 零件库标题下新增提示：装不上就去「设置 → 插件 → 市场」搜同名零件
- 修复：未传进度回调时安装会抛 `onProgress is not a function`
