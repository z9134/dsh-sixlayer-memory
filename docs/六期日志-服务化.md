## 3. 关键实现

**3.1 注册**

```js
const serviceName = config?.serviceName ?? 'memory'
if (ctx.get(serviceName)) { logger.warn('已被占用，跳过') }
else { ctx.provide(serviceName, buildService({ store, injector })) }
```

`ctx.provide` 返回 disposer，插件卸载时由 fiber 自动清理。

**3.2 recall 只给指针**

```js
const ptr = { record_id, layer, sad_level, created_at }
if (trust_level !== 'unverified') ptr.summary = snippet
```

正文（content）永远不出现在返回值里；S 级由 `store.search` 本身排除。

**3.3 forget 只归档**

`archive` → 状态置 `archived`；`downgrade` → `depth + 1`。两者都不删数据。

## 5. 注意事项

1. **同一宿主内的插件视为可信**：`principal` 由调用方声明，服务只做策略执行，不做身份伪造防护。跨进程/多用户的强身份要等宿主提供。
2. **服务名 `memory` 是约定**：以后若有同名插件，先探测再改名（`serviceName`）。
3. **消费方要能降级**：拿不到记忆就照常回答，不要因为记忆服务挂了就拒绝服务。
4. **只在宿主里可见**：客户端（浏览器）拿不到这个服务，客户端走 RPC。
