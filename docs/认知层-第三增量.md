# 认知层第三增量（B4）实施记录

日期：2026-10-31
版本：0.5.0 → 0.6.0
schema：v7（不变）

## 干了什么

观测页新增「近 14 天情绪趋势」：

- host：`observe` 端点增加 `trend` 数组
  - 每天 `{ day, n, bad, good }`
  - `bad` = negative + urgent 条数，`good` = positive 条数
  - 缺的日期补 0（保证 14 行对齐，不跳日）
- 客户端：14 行横向条形图
  - 红色段 = 负面占比，绿色段 = 正面占比，灰色 = 中性
  - 右侧文字：`N 条 · 负 X · 正 Y`

## 为什么用条形图而不是折线

情绪不是连续量，按天的构成比（负面占比）比"平均值折线"更诚实；
而且不引入图表库，保持零依赖。

## 怎么验证

`tools/p10.mjs`（5 项）：今天有数据、3 条、负面 1、正面 1、窗口 14 天。
全量回归：p1 15、p2 13、p3 10、p4 12、p5 24、p6 17、write-chain 20、smoke 19、phase2 23、tools 24、p8 15、p9 5、p10 5，全绿。

## 怎么读

- 连续几天红色占比高 → 这段时间在救火，值得回看那几天的记忆
- 绿色多但总量低 → 平静，但没有沉淀
- 全是灰色 → 存量旧数据（未回填情绪），或者写的是中性事实

## 注意事项

1. 趋势只统计 `status='active'`，归档/隔离/待审不计入。
2. 日期按 UTC 切（`created_at` 是 ISO UTC），本地显示会差 8 小时；如果你在意"本地日"，需要改成按东八区偏移分组。
3. 存量 25 条都在 10-31 之前，所以 14 天图里只有今天有柱子，属预期。
