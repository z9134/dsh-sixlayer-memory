# 发布说明

版本：1.7.0
包名：dsh-workbench（插件 id：workbench / workbench-service）

## 打包

```powershell
$src = "D:\001\CH002\dsh-memory-core"
$zip = "D:\001\CH002\_release\dsh-workbench-1.7.0.zip"
Compress-Archive -Path "$src\package.json","$src\README.md","$src\cordis.patch.yml","$src\lib","$src\catalog","$src\docs","$src\tools" -DestinationPath $zip -Force
```

## 发布到 GitHub

```bash
# 在 dsh-memory-core 目录
git init
git add package.json README.md cordis.patch.yml lib catalog docs tools .gitignore
git commit -m "dsh-workbench 1.7.0: 记忆底座 + 零件库 + 情绪观察 + 图查询 + 加密"
git branch -M main
git remote add origin https://github.com/<你的账号>/dsh-workbench.git
git push -u origin main
```

## 发布前检查（必跑）

```bash
npm run check   # preflight G1-G10 + 26 个测试套件
```

## 安装方式

```bash
# 官方 CLI（推荐）
dsh plugin --profile desktop add github:<你的账号>/dsh-workbench
# 或本地链接（开发）
cd ~/.dsh/profiles/desktop && pnpm add link:D:\001\CH002\dsh-memory-core
```

- 数据目录默认 `D:\001\CH002\dsh-memory-data`，不随包发布
- 加密默认关闭，`mem_crypto({action:"enable"})` 才生成密钥
- 30 个工具 / schema v9 / 26 个测试套件
