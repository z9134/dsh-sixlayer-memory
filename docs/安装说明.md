# 安装说明

适用于 DSH Desktop（`~/.dsh/profiles/desktop`）或 `dsh web`（`dsh-home/profiles/web`）。
前置：Node ≥ 22.5（`node:sqlite`）、DSH 0.2.x。

## 一、把插件挂进 profile

Windows 用目录联接（不需要拷贝代码）：

```powershell
$prof = "$env:USERPROFILE\.dsh\profiles\desktop"      # 或 dsh-home\profiles\web
$src  = "D:\001\CH002\dsh-memory-core"
New-Item -ItemType Junction -Path "$prof\node_modules\dsh-memory-core" -Target $src
```

## 二、注册 bundle

编辑 `profiles/<name>/package.json`，在 `dsh.profile.bundles` 里加：

```json
"dsh-memory-core"
```

## 三、写配置

编辑 `profiles/<name>/cordis.patch.yml`，追加：

```yaml
- insert:
    - id: memory-core
      name: dsh-memory-core
      config:
        dataDir: 'D:\001\CH002\dsh-memory-data'
        authority: shadow        # legacy=只走旧源 / shadow=并读 / new=新库为准
        api:
          enabled: true
          token: ''              # 留空自动生成到 dataDir\meta\api-token.txt
          allowWrite: false      # 默认只读
          port: 47810
```

可选：服务化（独立一行，挂了不影响主插件）

```yaml
- insert:
    - id: memory-core-service
      name: dsh-memory-core/service-plugin
      config:
        dataDir: 'D:\001\CH002\dsh-memory-data'
        serviceName: memory
```

## 四、重启并验证

重启 DSH 后：

1. `mem_admin_catalog` → 应列出 **24 个工具**
2. 设置 → 记忆底座 → 总览 → 记录数正确、审计「一致」
3. 对话顶栏出现「记忆」页签；右侧栏「开始」页出现「记忆」入口卡

## 五、可选通道

### HTTP API

```bash
TOKEN=$(cat "D:/001/CH002/dsh-memory-data/meta/api-token.txt")
curl -s "http://127.0.0.1:47810/status" -H "Authorization: Bearer $TOKEN"
```

详见 [HTTP-API说明.md](HTTP-API说明.md)。

### QQ 官方机器人

安装 `@tencent-connect/dsh-qqbot`，用它驱动 agent；agent 自带 `mem_*` 工具。
详见 [QQ官方机器人接入.md](QQ官方机器人接入.md)。

## 回退

1. 删除 `cordis.patch.yml` 里的 `memory-core` 段
2. 重启
3. 数据不动（`dataDir` 可保留，下次装回来直接读）

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 所有 `mem_*` 报 unknown tool | 插件行被删 / bundle 没注册 | 检查 `cordis.patch.yml` 与 `dsh.profile.bundles` |
| 启动崩溃 `Unexpected token ''` | 某个 profile `package.json` 带了 BOM | 用 Node 重写该文件（无 BOM） |
| 库版本高于代码 | 代码回退但库已迁移 | 升回代码版本，或从备份恢复库 |
| API 401 | token 不对 / 文件被改 | 重新读 `meta/api-token.txt` |
| 侧栏没有「记忆」 | 客户端 bundle 是旧版 | 确认已重启；F12 看 `[dsh-memory-core]` 警告 |
