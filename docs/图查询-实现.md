# 图查询实现（v9）

日期：2026-11-01
版本：1.5.0
schema：v9（新增 `edges` 表）

## 做了什么

把 `mem_graph_view` / `mem_graph_traverse` 从占位桩改成真实实现。

### 边怎么来

`edges(from_id, to_id, kind, weight, created_at)`，两种自动边：

| 类型 | 规则 |
|---|---|
| `tag` | 两条记忆共享同一个标签（无向，存一次 `from < to`） |
| `batch` | 同一 `batch_id` 写入的两条记忆 |

只连 `status='active'` 的记录。

构建：`store.buildEdges()`（清空重建，默认上限 5000 条边）。
查询时若 edges 为空会自动构建；也可以传 `rebuild: true` 强制重建。

### 查询

- `graphNeighbors(recordId, { hops: 1..3, edgeTypes })`：BFS，返回节点（带 depth/layer/summary）与边
- `graphTraverse(seedIds, { hops, edgeTypes })`：多种子 BFS，合并去重

### 工具

```
mem_graph_view({ record_id, hops?, edge_types?, rebuild? })
mem_graph_traverse({ seed_ids, hops?, edge_types?, rebuild? })
```
